# trohan

Website for **Trohan Electric & Construction** — electrical and construction services in New Westminster, BC.

Static site: plain HTML, CSS and JavaScript (no build step).

- `index.html` and the other `.html` files — pages
- `css/style.css` — design tokens (colours, type, spacing) + all styles
- `css/hero-story.css`, `js/hero-story.js` — hero "how a job works" animation
- `js/motion.js` — GSAP scroll reveals · `js/smooth-scroll.js` — Lenis smooth scrolling
- `js/main.js` — nav dropdowns, mobile menu, forms, before/after slider

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy
Hosted with GitHub Pages from the `main` branch (root folder).
